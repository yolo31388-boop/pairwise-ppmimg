帮我用 Python 写一个图像处理的小库，纯标准库实现，不依赖 PIL/OpenCV 这些。我有一批 PPM 格式的图片想批量做滤镜处理。

需求大概这样：
- 解析和保存：支持读 PPM 图片（P3 文本格式和 P6 二进制格式都要支持），保存也支持两种格式
- 一个 Image 类：宽、高、像素数据（RGB），支持 get_pixel / set_pixel
- 滤镜函数（都返回新 Image，不修改原图）：
  - 转灰度：to_grayscale
  - 反色：invert
  - 亮度/对比度调整：adjust_brightness(factor)、adjust_contrast(factor)
  - 高斯模糊：gaussian_blur(radius)，半径 1-5 可调
  - 锐化：sharpen()
  - 边缘检测：sobel_edge()（输出灰度图，边缘亮）
  - 缩放：resize(width, height)，用双线性插值
  - 旋转：rotate(90/180/270)
- 边界处理：模糊和边缘检测在图像边缘处要正确处理（比如像素越界按边缘像素复制），不能崩

约束：
- 只准用 Python 标准库
- pytest 可以当测试工具用，但运行时不能依赖

我验收会这么测：
1. 生成一张 4x4 的测试图（已知像素值），读进来像素值和写进去的一致，P3/P6 两种格式互转不丢像素
2. 灰度：纯红 (255,0,0) 转灰度后 R=G=B，按公式算出来核对
3. 反色：255 变 0，0 变 255
4. 模糊：纯色图模糊后还是同色；黑白交界处模糊后出现中间值
5. Sobel：纯色区域输出接近 0，垂直边缘处输出高值
6. resize：2x2 放大到 4x4，尺寸对，双线性插值结果和手算一致
7. 性能：一张 800x600 的图，gaussian_blur(3) 和 resize 单次操作不超过 10 秒
